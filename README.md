# Clinic Appointment Booking System

A full-stack web application designed to streamline the appointment booking process for clinics and medical practices. Built with **Python, Django, and PostgreSQL**.

## 🚀 Features
*   **User Authentication:** Secure login and logout functionality using Email.
*   **Dynamic Booking System:** Users can select a doctor, service, and view available time slots dynamically.
*   **Double-Booking Prevention:** Advanced logic ensures no two patients can book the same doctor at the same time.
*   **User Dashboard:** A personalized dashboard where users can view, manage, and cancel their appointments.
*   **Review System:** Patients can leave ratings and comments for doctors after their appointments.
*   **Responsive UI:** A modern, mobile-friendly interface built with Bootstrap 5.

## 🛠️ Tech Stack
*   **Backend:** Python, Django
*   **Database:** PostgreSQL
*   **Frontend:** HTML5, CSS3, Bootstrap 5, FontAwesome
*   **Environment Management:** Python-dotenv
